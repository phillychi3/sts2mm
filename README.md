# Slay The Spire 2 Mod Manager

Slay the Spire 2 模組管理工具，支援模組安裝/啟用/停用，以及存檔備份與還原

## 功能

- **模組管理**：匯入、啟用、停用、卸載模組，本地與 Steam 工作坊模組統一管理
- **存檔管理**：備份與還原存檔
- **工作坊同步**：匯出工作坊模組清單，讓隊友一鍵下載相同模組


## 安裝

### 下載預編譯版本

至 [Releases](https://github.com/phillychi3/sts2mm/releases) 頁面下載對應平台的執行檔，解壓縮後直接執行



## 使用方式

### 首次設定

1. 將 `sts2mm` 執行檔放在任意目錄後啟動
2. 程式啟動時會自動偵測 Steam 遊戲目錄，並儲存偵測結果
3. 若偵測失敗，請確認 Steam 已安裝且遊戲已下載完成，再切換至「設定」頁面重新偵測

### 匯入模組

按 `I` 開啟匯入畫面，將 `.zip` 檔案或模組資料夾**拖入視窗**，或者手動輸入，按 `Enter` 確認安裝

> 首次安裝模組時，若 mod 存檔槽尚無存檔，程式會詢問是否將一般存檔複製到 mod 槽，以便延續原本進度

### 啟用與停用

模組列表會同時列出 `mods` 資料夾與**已訂閱**的工作坊模組，並標示來源。啟用狀態直接寫入遊戲的 `settings.save`（與遊戲內模組畫面的開關相同），不再搬移資料夾


> 遊戲執行中會覆蓋設定檔，請先關閉遊戲再切換模組。工作坊模組無法卸載，請在 Steam 取消訂閱。
> 舊版放在 `mods_disabled` 的模組會標示為「舊停用」，啟用時會自動搬回 `mods`。

### 工作坊同步（多人連線）

**玩家 A**：進入「工作坊」頁面按 `E`，程式會掃描已訂閱的工作坊模組，輸出 `workshop-list-*.json`，並將 ID 複製到剪貼簿。把檔案或 ID 傳給隊友

**玩家 B**：進入「工作坊」頁面按 `S`，拖入清單檔或貼上 ID／工作坊網址，選擇下載方式：

1. **Steam 客戶端（Steamworks）**（僅 Windows）：需開著 Steam，透過遊戲附帶的 `steam_api64.dll` 下載，不用登入，也不會訂閱
2. **SteamCMD**：需安裝 [steamcmd](https://developer.valvesoftware.com/wiki/SteamCMD)

下載完成後會複製到遊戲的 `mods` 資料夾，覆蓋同名模組，並自動存成模組包

> 不是來自工作坊的模組無法用這個方式同步，匯出時會列出這些模組，請改用「模組包」導出
